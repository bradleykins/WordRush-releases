# Word Rush for Android

Download the latest version: **[Releases → Latest](https://github.com/bradleykins/WordRush-releases/releases/latest)** → tap `WordRush-<version>.apk` under *Assets*.

## Install

1. Open the downloaded `.apk` on your phone.
2. If Android asks, allow your browser or Files app to **install unknown apps** (Settings → Apps → Special app access → Install unknown apps).
3. Tap **Install**, then open Word Rush.

## Update

Download the newest APK the same way and install it over the old one. Your name, league and stats are kept.

If the app ever says a new version is needed, come back here for the latest one.
